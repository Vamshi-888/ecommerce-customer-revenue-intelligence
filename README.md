# E-commerce Customer & Revenue Intelligence

## Overview
A data analytics portfolio project using the Brazilian E-Commerce Public Dataset by Olist to analyze orders, item revenue, customer behavior, and delivery performance.

## Tools & Technologies
- PostgreSQL
- Python (Pandas, Matplotlib)
- Tableau

## Analysis
- Monthly order trends
- Item revenue and shipping charge analysis
- Customer purchasing patterns
- Delivery performance
- Review scores and data quality checks

## Project Structure
- `sql/` — SQL analysis queries
- `scripts/` — Python analysis and database scripts
- `outputs/` — Summary CSV files and charts
- `Data/` — Raw dataset files, downloaded separately and excluded from GitHub

## Dataset
Brazilian E-Commerce Public Dataset by Olist

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## How to Run
1. Download the dataset into the `Data/` folder.
2. Install the required Python libraries: `pandas`, `matplotlib`, and `psycopg[binary]`.
3. Set up PostgreSQL and configure the database connection settings.
4. Run the required Python scripts in `scripts/`.
5. Execute the SQL queries in `sql/`.
6. Open the Tableau workbook to explore the dashboard.

## Note
This project is intended to demonstrate data analytics skills. Item revenue, shipping charges, and recorded payment values are separate measures.
